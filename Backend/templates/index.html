Pathfinder 1E Randomized Character Generator

This is a JSON API, not an application. Generate a character by POSTing the input values to /update_character_data.

The character sheet that used to live at /sheet has been retired. Its replacement is the standalone Pathfinder-Character-Sheet front end, which points at this backend.
